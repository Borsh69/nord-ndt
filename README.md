# NORD-NDT — Company Services Website

A company website developed for **NORD-NDT**, a company specializing in non-destructive testing (NDT), industrial inspection equipment, radiographic image digitization, equipment verification, maintenance, and software solutions.

This project focuses on presenting the company's services in a clear and accessible format.

## About the Project

The website was created as an informational corporate website for NORD-NDT.

Its main purpose is to introduce potential customers to the company's services, technologies, and areas of expertise without recreating the full product catalog of the original website.

## Main Services Presented

* Non-destructive testing solutions
* Radiographic image digitization
* Measurement equipment verification and calibration
* NDT equipment repair and maintenance
* Technical support and equipment servicing
* Industrial inspection equipment
* Software development for NDT and diagnostics
* MARS NORD radiographic inspection systems

## Features
